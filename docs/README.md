# docs/ — リポジトリ横断の設計ノート

このディレクトリは、特定のセクション（`pipeline/` など）単体に閉じない、
**複数セクションをまたぐ設計提案・検討資料**を置く場所です。

セクション固有のドキュメントは各セクションの `README.md` に置き、ここには
「どのセクションに実装するかを含めて検討する段階」の資料を置きます。
