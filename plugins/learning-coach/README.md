# learning-coach — 人間の側の理解を作る学習コーチ

Claude を**教師役**に固定し、ある変更・コード・設計判断を、**あなた自身が人に説明できる状態**に
なるまで段階的に教えるプラグインです。スキルは `deep-understand` の1種。

このリポジトリの他のプラグインが「Claude に良い仕事をさせる」ためのものであるのに対して、
これは**あなたの理解を作る**ことだけを担当します。Claude に書かせた変更をレビュー・マージ・
説明する前に、中身を自分のものにするために使います。

| 項目 | 内容 |
|---|---|
| 使い方 | `/deep-understand [対象]`、または「この変更を理解したい」「なぜこうしたのか教えて」等の自然文 |
| フェーズ | 対象確定 → チェックリスト提示 → 診断 → 段階指導ループ（説明→クイズ→補修）→ 統合 → 完了判定 |
| 出力 | 会話内のみ（3層チェックリストを毎ターン更新して提示）。ファイルは書かない |
| 依存 | なし（外部 CLI・ネットワーク・サブエージェント不要） |

## どれを選ぶか

| やりたいこと | 使うもの |
|---|---|
| 1つの疑問にすぐ答えてほしい | 通常の応答（1問1答に教師役は過剰） |
| **中身を理解して、自分で説明できるようになりたい** | **`/deep-understand`（本プラグイン）** |
| コードの欠陥・改善点を挙げてほしい | `/code-review`、[`codex-bridge`](../codex-bridge/)、[`agent-review-panel`](../agent-review-panel/) |
| 成果物が完了条件を満たすか検証したい | `verify-fresh`（[`model-setup`](../model-setup/)） |
| Claude がリポジトリを読みやすくする足場 | `codebase-onboard`（[`codebase-setup`](../codebase-setup/)） |
| 理解した内容を記録に残したい | `notes`（[`pipeline`](../pipeline/)）。理解の実証が済んでから |

## なぜこの構成か

出典は 2026-08-11 に共有された Anthropic メンバーの「仕事の学習用プロンプト」。都度貼りで使うには
長く、貼り忘れれば効きません。**プロンプトは一時的、構造は永続的** — スキルとして常設化しました。

原型の核は4点で、いずれも「説明を出力して終わり」を防ぐためのものです。

1. **診断が先、講義は後** — まずユーザー自身に現在の理解を述べさせ、その差分を埋める
2. **3層チェックリスト** — ①問題（なぜ起きたか・別解）②解決（なぜその方法か・設計判断・
   エッジケース）③広い文脈（なぜ重要か・何に影響するか）。**①問題の理解を最優先**
3. **クイズで実証** — `AskUserQuestion` で出題し、**全問の回答が返るまで答えを明かさない**
   （ツールの構造でカンニングを防ぐ）。**正解の選択肢の位置は毎回変える**
4. **全項目が実証されるまで終えない** — 「わかりました」は実証ではない。再説明・転移・
   エッジケースの予測の3点がそろって初めて合格

### 見送ったもの（設計ノート）

- **サブエージェントへの委譲** — 理解はユーザーとの往復でしか作れないため、説明役を
  サブエージェントに切り出す意味がない。よってエージェントは持たない
- **フック** — 学習セッションは明示的に始めるもので、自動発火させる対象ではない
- **本体 `/goal` の再実装** — `/goal` はチェックリストの完了判定を持つが、診断・段階指導・
  クイズ・合格判定は持たない。重複させず、外側の完了ゲートとして併用する

## ファイル構成

```
learning-coach/
├── README.md                         # このファイル
├── .claude-plugin/plugin.json        # プラグインマニフェスト
└── skills/
    └── deep-understand/SKILL.md      # 段階的な理解の指導（中核ルール・フロー・クイズの作り方）
```

## 導入方法

### 方法1: プラグインで導入する

```
/plugin marketplace add mrkxlia/claude-code-workbench-ja
/plugin install learning-coach@workbench-ja
```

### 方法2: コピーして導入する

スキルを、使いたいプロジェクトの `.claude/` にコピーします。

```bash
mkdir -p .claude/skills
cp -r plugins/learning-coach/skills/*  .claude/skills/
```

グローバルに使いたい場合は `~/.claude/skills/` にコピーします。

## 使い方の例

```
/deep-understand この変更
/deep-understand @src/auth/session.ts
/deep-understand このセッションでやったこと
/deep-understand ELI14 で リトライの仕組み
```

自然文（「この変更を理解したい」「なぜこうしたのか教えて」「解説して」「勉強させて」
「引き継げるように理解させて」）でも発動します。

途中でいつでも粒度を指定できます。

| 指定 | 対象読者 | 説明の粒度 |
|---|---|---|
| `ELI5` | 5歳児 | 専門用語ゼロ・比喩1つ・全体像だけ |
| `ELI14` | 14歳 | 用語はその場で定義・仕組みの流れ・具体例1つ |
| `ELII` | インターン | 実務の語彙・実際のコード・データの流れ・エッジケース（既定） |
