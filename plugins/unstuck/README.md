# unstuck — Claude Code の堂々巡りに気付き、抜け出す mod（同梱）

[sniperunder123/unstuck](https://github.com/sniperunder123/unstuck) を**無改変で同梱**したものです
（MIT、上流コミット `5bf7196`・2026-10-08、2026-10-10 取得）。上流の README は [`README.upstream.md`](README.upstream.md)（英語）。

テストが同じ理由で何度も落ちる、「直した」のに同じ失敗が出る、といった**堂々巡り**をその場で見つけ、平易な言葉で知らせ、
1キーで抜け出す手段を出します。

## 何を見るか

| 信号 | 意味 |
|---|---|
| 同じエラー | 同じエラーが繰り返し出る（行番号・フォルダ・アドレス・時間は無視して比べる） |
| 同じコマンド | エラーの中身は変わっても、同じコマンドが失敗し続ける |
| 見せかけの修正 | Claude が「直した」と言った直後の実行で、同じ失敗が出る |
| ピンポン | Claude が以前消したコードを書き戻す |
| エラーの握りつぶし | `@ts-ignore`・`as any`・`.skip()`・`eslint-disable`・`# type: ignore` などでエラーを消す |
| 文脈が満杯 | 堂々巡りの最中に文脈が 80% を超えた（続けても良くならない） |

信号ごとに点数が上がり、🟡（かもしれない）・🔴（詰まっている）になります。

## 何をするか

- **あなたに知らせる**: 信号ごとのトースト、堂々巡りの間だけのステータスライン、🔴 のときプロンプトの上の赤い帯
- **Claude に伝える**（既定で有効）: 🔴 のとき、編集をやめて試したことを並べ、新しい仮説を3つ立ててから手を付けるよう、
  ツールの結果に一文を添える。エラーを握りつぶしたときは根本原因を直すよう伝える。**握りつぶしの編集を止める設定は既定で無効**
- **1キーで抜け出す**（`/unstuck` のペイン。どれもあなたがボタンを押したときだけ動く）

| 抜け出し方 | 何が起きるか |
|---|---|
| ⏪ 最後に通った状態へ戻す | テストやビルドが最後に通った時点へ、**追跡中のファイルだけ** `git restore` で戻す。先に作業ツリーのスナップショット（`git stash create`）を取り、元に戻すコマンドをトーストで出す。追跡していないファイルには触れない |
| 🧹 きれいにやり直す | 引き継ぎメモ（目的・失敗したこと・繰り返さないこと）を `$.model.fork` で書き、セッションを `/clear` して、メモをプロンプト欄に入れる（送信はあなたが押す） |
| 🔎 別の見立て | 汚れていない文脈の新しいエージェントにコードを読ませ、根本原因を探させる。Explore（読み取りのみ）で起動し、それが断られたときは既定の種類（書き込みもできる）で起動し直す |
| 🔬 先に診断 / 🌐 エラーを検索 | 推測の代わりにログや最小の再現、またはエラー文の Web 検索を頼むプロンプトを、プロンプト欄に入れる |

- **行き止まりを覚える**: やり直しと別の見立ての結果を、mod の私的な保存領域（プロジェクトの外）に 14日・5件まで残し、
  次のセッションで同じことを試さないよう伝える。`/unstuck dead-ends` で見て、`/unstuck forget` で消す

## なぜ同梱したか

このリポジトリで作っていた progress-pane の詰まり検知（ループごとの3回連続失敗）を、公開 mod と読み比べた（2026-10-10）。
エラーの中身を正規化して比べる・見せかけの修正や握りつぶしまで見る・抜け出す手段を持つ点でこちらが大きく上回っていたため、
自作をやめて同梱した。task-band の「ターン中15分どのタスクも完了しない」は、エラーが出ていない停滞を見る別の軸として残している。
経緯は [`docs/decisions/2026-10-08-tsundoku-task-band-mod.md`](../../docs/decisions/2026-10-08-tsundoku-task-band-mod.md)。

## 同梱するときに確かめたこと

- **ライセンス**: MIT。[`LICENSE`](LICENSE) をそのまま置いている。ソースは改変していない
- **危うい操作（ソースで確認）**: `git`（`stash create`・`rev-parse`・`restore`）を実行するのは「⏪ 戻す」のボタンを押したときだけ。
  ネットワークへの直接の通信は無い。`$.model.fork`（引き継ぎメモ）と `$.agent.spawn`（別の見立て）はボタンを押したときだけで、
  トークンを使う。設定と行き止まりは `$.store` に保存する
- **同梱しなかった上流のファイル**: `demo/`（デモ用のテスト対象）・`docs/make_images.py`・上流の `.claude-plugin/marketplace.json`
- `claude plugin validate` と、上流のテスト（`claude plugin test`、19件）が通ることを確認した。実機での動作は確かめていない
